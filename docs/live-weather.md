# Погода в LIVE

OpenF1 передаёт температуру воздуха/трассы, ветер, влажность и бинарный замер дождя, но не облачность. Небо дополняется модельными текущими условиями Open-Meteo из существующей таблицы `circuit_weather`, строго по `race_id` выбранной сессии. В погодном попапе указаны источник и время этой оценки; это не дополнительный датчик трассы.

Существующая задача `weather.sync_weekend` теперь запрашивает `weather_code`, `cloud_cover` и `is_day` в `current`. Ранее она сохраняла `current.weather_code`, не запрашивая его, поэтому поле оставалось пустым. Новых таблиц, переменных окружения и клиентских запросов к провайдерам нет. LIVE перечитывает кеш раз в минуту; само обновление погоды сохраняет существующий график задачи (30 минут). В рабочую базу при разработке ничего не записывалось.

Кеш и наблюдение должны быть не старше часа; будущие/невалидные значения отвергаются. Старые свежие записи могут использовать код последнего прошедшего часа из уже сохранённого hourly, но не будущий прогноз. Пока провайдер не передал день/ночь, ясное небо обозначается «Ясно» с нейтральным значком солнца/луны. Смена этапа очищает дополнение.

Дождь с трассы перекрывает модельное ясное небо. Если трасса сообщает отсутствие дождя, а модель — осадки, показывается доступная облачность; при её отсутствии — «Без осадков». Без данных отображается «Погода —». Иконки соответствуют состояниям, ночью используется луна. Температура и остальные замеры OpenF1 сохраняют свой источник.

Дополнение входит в общие опубликованные снимки: при перемотке возвращается известная тогда погода, а срок свежести проверяется по времени просмотра. В симуляторе и полном Replay текущая погода из базы не подмешивается к истории.

Проверки: `worker/live/weather.test.mjs` и `src/features/live/lib/weather.test.mjs` проверяют свежесть, UTC, день/ночь, приоритет датчика, старые кеши, ошибки базы, смену сессий и перемотку. Доступ к существующим полям базы проверен запросом только для чтения; расширенный запрос Open-Meteo проверен по публичным координатам Монцы.

Источники: [погода OpenF1](https://openf1.org/docs/#weather), [параметры и WMO-коды Open-Meteo](https://open-meteo.com/en/docs).
