# Попап отчёта о прошедшем Гран-при

Обновлён существующий отчёт, который открывается из карточки завершённого этапа. Сохранены адрес с `raceReport`, закрытие с возвратом на этап и кнопка публикации итогов через существующий интерфейс.

## Содержание

- **Обзор:** подиум, лучший круг, пит-стоп, выигранные позиции и число финишировавших. Раздел «Что обсуждали вокруг этапа» показывает существующий текст AI на основе новостей; генерация текста не менялась.
- **Позиции и отрывы:** выбор до шести пилотов, графики по кругам и подсказки с местом или временем в секундах.
- **Темп и стратегия:** история шин, гоночный темп, пит-стопы и условия гонки.
- **Итоги:** полная классификация с лучшим кругом каждого пилота, изменения позиций, сравнение напарников и чемпионат до/после этапа.

Блока ключевых моментов и выводов о том, что решило гонку, нет. Раскрывающиеся блоки «Данные графика» и «Лучшие круги и составы шин» убраны. Внизу остаётся только время обновления.

## Данные и ограничения

Дополнительные графики читают сохранённые данные Race Replay и Race Pace на сервере. Открытие отчёта не запускает сбор телеметрии и не обращается к внешним F1 API. Новые зависимости и миграции не добавлены.

Пустые, устаревшие и повреждённые значения не превращаются в нули. Пит-стопы, круги под флагами, пропуски и смена шин разрывают линию темпа. В старых повторах позиции берутся из последнего сохранённого замера на круге; время круга из геометрии не рассчитывается. При отсутствии длительности пит-стопов показано количество остановок. Раздел чемпионата требует полных снимков непосредственно до и после этапа; очки включают спринт, если он был.

## Проверки

- TypeScript: `pnpm typecheck` — успешно.
- Lint изменённых файлов — успешно. Проверка всего исходного кода с исключением `.track-model-build/**` — успешно.
- 54 теста отчёта, подсказок, отображения результатов, гоночного темпа и доступа — успешно; восемь проверяют модуль отчёта, три — форматирование подсказок.
- Production-сборка проверена в отдельной временной копии через `next build --webpack`. Дисковый кеш Webpack отключён только в этой копии из-за недостатка свободного места; конфигурация проекта не менялась.
- Браузер: тёмная/светлая темы, ширина 1440 и 375 px, переходы между разделами, раскрытие 22 пилотов, чемпионат до/после этапа, ограничение фокуса внутри попапа и закрытие по Escape.

Общие проверки проекта имеют отдельные ограничения: `pnpm lint` захватывает сгенерированные файлы `.track-model-build`; `pnpm test:telemetry` содержит один падающий тест отсутствующей геометрии Yas Marina (114 тестов проходят). Эти файлы и геометрия не изменялись в рамках отчёта.
