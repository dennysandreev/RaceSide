## Проверки приложения

### Уточнение T10, 4 октября 2026

В исходной OSM-оси смещение относительно середины видимого асфальта доходило до 5,55 м. Вместе с постоянной шириной 12 м это оставляло заметную часть дорожного полотна вне 3D-сетки. Ось и ширина только way 138566993 уточнены по парным краям GeoSampa 2020; концы way сохранены. Локальная ширина — 11,10–16,75 м. Вместе с полотном изменены поребрики, краевая разметка, T10 anchor и подготовка рельефа.

Независимая проверка сжатого GLB с точками в 1 м от обоих видимых краёв: старый ассет пропускал 26 из 52 проб, новый покрывает 52 из 52. Python-регрессия сначала воспроизвела смещение 4,50 м, после правки обе проверки прошли. Профильные Node-тесты: 30 из 30; lint и typecheck прошли. Контрольные изображения сняты с одинаковой камерой: [до, сверху](track-model-interlagos-review/t10-before-top.webp), [после, сверху](track-model-interlagos-review/t10-after-top.webp), [после, объём](track-model-interlagos-review/t10-after-angle.webp), [совмещение с источником](track-model-interlagos-review/t10-source-alignment.png), [браузер, 800%](track-model-interlagos-review/t10-local-800.png). Координаты и хеш снимка: [станции коррекции](track-model-interlagos-t10-corridor.json). Неопределённость интерпретации края ±0,75 м; инструментальная точность не заявляется.

- Полная воспроизводимая offline-сборка, source hashes, validator и аудит сжатой геометрии прошли.
- Профильные тесты модели, подключения и камеры прошли.
- `pnpm lint` и `pnpm typecheck` прошли.
- Production build прошёл: 55 страниц. Локальная изолированная копия использовала `--webpack`, поскольку Turbopack отклоняет внешний symlink `node_modules`; конфигурация проекта для этого не менялась. Первая изолированная серверная сборка со штатным Turbopack также прошла. Повторная серверная сборка после добавления preview завершилась SIGTERM (143) на этапе TypeScript; причина сигнала не подтверждена. Для итогового образа использована успешная сборка с одним дополнительным разрешённым путём preview в двух сериализованных Next.js-конфигурациях; JavaScript и геометрия успешной сборки не изменялись. Работа оптимизатора проверена HTTP-запросом и в браузере.
- Python-скрипты прошли синтаксическую проверку.
- Проверены viewport 375, 768, 1024, 1440 px, светлая/тёмная тема, fullscreen, вид сверху, 800%, reset, pan, сфера и клавиатура. Горизонтального переполнения нет. Жесты двумя пальцами проверены существующими тестами камеры; физических iOS/Android-устройств и FPS-замеров не было.
- До открытия 3D начальный HTML не содержит GLB, полного массива геометрии или версии ассета; модель импортируется отдельным динамическим модулем.
- При намеренном HTTP 503 только для GLB через отдельный локальный прокси отображается настоящее статическое preview. Обнаруженный отказ оптимизатора изображения устранён добавлением одного пути в `images.localPatterns`.
- Нормальный просмотр проверяется отдельно от намеренного отказа. Ошибки искусственного отказа ожидаемы; в нормальном просмотре ошибок JavaScript/WebGL не обнаружено.

## Публикация

Финальная сборка T10 прошла локально с Webpack: 55 страниц, точные исходники опубликованного Shanghai-релиза плюс только новая модель Interlagos. Во время подготовки защитная проверка обнаружила переключение production с образа `731e4654021d` на `afbe4a11ed9d`; старый кандидат не был опубликован, сборка перенесена на новый релиз. GLB Shanghai `6dc203b0e2501d41679f9762b8d201543cac2badf322c14d2c03f1ce1876639b` сохранён. Проверочный контейнер создан на основе этого действующего образа сайта. Для T10 заменены только клиентские данные Interlagos, GLB, preview и metadata; общий просмотрщик используется существующий. Прочие незавершённые изменения общего рабочего каталога не включались. Перед переключением проверены хеш текущего образа, исходные файлы, окружение, здоровье кандидата и содержимое GLB.

Опубликовано на [странице Гран-при Бразилии](https://raceside.online/calendar/2026/20). Контейнер `racemate-web` после переключения имеет статус healthy. Публичный 3D-просмотр проверен на desktop и при ширине 375 px, включая fullscreen и кнопки масштаба; в нормальном просмотре ошибок JavaScript/WebGL не обнаружено.

## Ограничения приёмки

Это реконструкция постоянной трассы с раскрытыми ограничениями, а не полная подтверждённая модель события 2026. Ортофото — 2020, LiDAR — 2017, FIA controls — 2025; вертикальный датум не полностью подтверждён. Временные event-трибуны и моторхоумы 2026 отсутствуют без надёжной геометрии. Поэтому критерий полной текущей event-инфраструктуры из playbook остаётся неподтверждённым; приблизительные фасады/высоты/формы и номинальная ширина дороги также явно перечислены в source card и metadata.
