## Браузерная приёмка

Серверный кандидат проверен при 375, 768, 1024 и 1440 px в светлой и тёмной теме. После готовности WebGL размер canvas совпадает с viewport; панель управления остаётся внутри экрана, горизонтального переполнения нет. На мобильном экране кнопка «3D» открывает карту сразу в fullscreen. Проверены fullscreen, 800%, отдаление, Home/reset, клавиатурный вид сверху, drag сферы и перемещение карты. Номера поворотов привязаны к геометрии. Физические жесты iOS/Android не проверялись; расчёт pinch/orbit покрыт тестами общего контроллера.

В обычном просмотре ошибок JavaScript/WebGL нет. Three.js сообщает о deprecated `THREE.Clock`; сообщения Context Lost возникают при штатном размонтировании canvas между карточкой и fullscreen. Это существующее поведение общего просмотрщика.

Начальный HTML не содержит `las-vegas.glb` или полного массива геометрии. При намеренном HTTP 503 только для GLB показывается настоящий WebP preview, `naturalWidth > 0`, opacity 1. Оптимизатор изображения возвращает результат; после теста перехват снят. Ошибки этого искусственного отказа рассматриваются отдельно от обычного просмотра.

## Ограничения

Это реконструкция, а не полная подтверждённая модель события 2026. NAIP — 2022, FIA controls — 2025; спортивная схема 2026 пока отсутствует. Ширины, точные footprint/размеры временных трибун, фасадные модули и часть высот оценочные; LoD2/DSM не получены. Неустановленные моторхоумы 2026 и мелкие сервисные объекты не добавлены. Профиль предназначен для обзора рельефа, а не инженерных измерений. На физических телефонах и по FPS модель не измерялась.
