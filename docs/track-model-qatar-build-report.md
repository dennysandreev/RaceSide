# Qatar / Lusail — проверка модели

5 октября 2026. Новая Blender-модель заменяет схему в режиме «3D» на странице `/calendar/2026/22`, через существующий lazy loader и общий просмотрщик RaceSide. Полный набор источников и ограничений: [карточка источников](track-model-qatar-source-card.md).

Модель: ось 5417,922 м против FIA 5419 м, ошибка 0,019888%; 16 поворотов, 50 гаражных позиций, непрерывный пит-лейн с fast lane, физической стеной и catch fence. 141 картографированное здание, шесть блоков трибун, четыре постоянных hospitality-павильона, картографированные деревья и ограждения. Все физические объекты окрашены по фотографиям/разрешённому спутниковому источнику и имеют встроенные текстуры. Высотный профиль приблизительный, без вертикального усиления.
