RaceSide — единый логотип

Горизонтальный: raceside-horizontal-dark.svg / -light.svg.
Вертикальный: raceside-stacked-dark.svg / -light.svg.
Одноцветные версии: -black.svg, -white.svg, -red.svg.
С подписью «Гоночный центр»: raceside-signature-dark.svg / -light.svg.
Отдельный знак: raceside-mark-red.svg / -black.svg / -white.svg.
Аватары: raceside-avatar-dark.svg / -light.svg / -red.svg.

dark/light означает фон, на котором следует размещать логотип.
Все файлы прозрачные, кроме готовых квадратных аватаров.
Текущая айдентика — «Траектория»: две встречные ленты образуют компактный знак S.
Название RaceSide переведено в контуры из Geist Sans (wght 800).
Для открытия SVG шрифты и внешние ресурсы не нужны.

SVG рассчитаны на RGB/sRGB. Для печати требуется проверка цвета.
Масштабируйте логотип пропорционально и сохраняйте свободное поле.

PNG, обзор, рекомендации и лицензия шрифта:
output/raceside-trajectory-kit/

Логотип внедрён в интерфейс, карточки для публикации, favicon и Apple Touch Icon.
В интерфейсе используются RaceMateLogo / RaceMateMark / RaceSideLogoSvg
из src/components/racemate/racemate-logo.tsx. Общая векторная графика находится
в src/components/racemate/raceside-logo-artwork.ts; название не зависит от шрифта.
avatar-dark.png — квадратная версия 512 × 512 для метаданных сайта.
avatar-trajectory-dark.png — та же актуальная версия с новым именем для обновления кэша.
RaceSide Plus: raceside-plus-horizontal-* / -signature-* — название с плюсом;
raceside-plus-mark-* — самостоятельный знак с плюсом; -avatar-* — готовые аватары.
Версия с подписью применяется в меню, подвале и крупных карточках;
горизонтальный вариант без подписи — в компактных блоках. Узкие блоки используют только знак.
Подробные правила: DESIGN.md, раздел RaceSide logo system.
Генератор SVG, PNG, иконок и локальной графики Telegram: scripts/generate-raceside-brand.mjs.
Обновление логотипов в публичных скриншотах Plus: scripts/refresh-raceside-brand-previews.mjs.
