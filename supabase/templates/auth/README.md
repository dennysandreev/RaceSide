# Письма RaceSide

Восемь русских шаблонов Supabase Auth используют единое оформление и утверждённый логотип «Траектория». Исходный текст и вёрстка находятся в `scripts/build-auth-email-templates.mjs`; HTML и темы писем генерируются рядом с этим файлом.

```sh
node scripts/build-auth-email-templates.mjs
node scripts/configure-supabase-email-templates.mjs
python3 -m http.server 8877 --bind 127.0.0.1 --directory output/auth-emails
```

Превью: `http://127.0.0.1:8877`. В нём используются демонстрационные адреса и код; ссылки не предназначены для авторизации. Оригинальные шаблоны сохраняют `{{ .ConfirmationURL }}` и текущий PKCE callback. Подтверждение регистрации и восстановление требуют того же браузера, в котором начат запрос.

Для повторного переноса через Management API используйте имеющийся `SUPABASE_ACCESS_TOKEN` и `node scripts/configure-supabase-email-templates.mjs --apply`. Скрипт сохраняет прежние темы и HTML в игнорируемый каталог `output/auth-emails/backups`, меняет только 16 полей шаблонов и читает их обратно для проверки. SMTP, URL, лимиты, политики и переключатели уведомлений сохраняются.

Логотип экспортируется из утверждённого SVG в `public/brand/raceside/email-signature.png` (844 × 264). Письма используют публичный неизменяемый PNG в отдельной папке `brand` существующего `driver-avatars`, путь `brand/raceside-email-signature-v1.png`. Этот бакет уже разрешает PNG; настройки доступа и типов файлов не меняются. Перед установкой шаблонов файл должен быть загружен и доступен без авторизации. В локальном превью PNG встроен только для автономного просмотра.

Уведомления о смене пароля и почты отправляются, только если соответствующие настройки включены в Supabase. Обычный вход с паролем письма не отправляет; magic link, приглашение и код используют отдельные сценарии Supabase и не включаются этим изменением.

Вёрстка: таблицы, inline CSS, системный Arial/Helvetica, PNG вместо SVG, текстовая запасная ссылка, Outlook fallback для ширины и кнопок. Светлая тема работает без media queries; поддерживаемые клиенты получают тёмную тему и мобильные отступы. Автоматическая инверсия Gmail/Outlook может отличаться от превью. Доставку и переход по реальному одноразовому письму нужно проверять отдельно.

Документация: https://supabase.com/docs/guides/auth/auth-email-templates
